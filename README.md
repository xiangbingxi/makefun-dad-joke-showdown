This is my entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun.

## The joke

> The mechanic told me my car needed a new muffler. I said, “Keep it quiet.”

## How it works

Run `main.py`. It writes the joke verbatim — no trailing newline, no extra
characters — to `/output/entry.txt`. The output is deterministic: running it
twice produces byte-identical files.
